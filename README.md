# data-science-mondrian-art-analysis
This repository contains projects from the Cisco Networking Academy Data Science Essentials with Python course. 

It explores patterns inspired by the works of Piet Mondrian, applying data analysis and visualization techniques using Python (Pandas, Matplotlib).


## Data Sources

Images were downloaded from the website http://pietmondrian.rkdmonographs.nl (Catalogue Raisonné).

We wrote algorithms to extract the features from each painting.
